# FSC Utilities

Small utilities for splitting MRC volumes and computing Fourier correlation metrics.

## Files

- `fsc.py`: As a library - to compute Fourier Shell/Ring Correlation for 3D/2D arrays using checkerboard half-map splitting.
- `fsc.py`: As a script - to compute Fourier Shell Correlation for a given MRC file.
- `fsc.ipynb`: Notebook for interactive experimentation.
